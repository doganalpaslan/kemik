# Fonts

Self-hosted, unmodified WOFF2 files from Fontsource:

- Inter 5.3.0, weights 400 / 500 / 600 / 700, Latin and Latin Extended. Copyright the Inter Project Authors. https://www.npmjs.com/package/@fontsource/inter/v/5.3.0
- Source Serif 4 5.3.1, weight 400, Latin and Latin Extended. Copyright Adobe. https://www.npmjs.com/package/@fontsource/source-serif-4/v/5.3.1

Both are licensed under SIL Open Font License 1.1; see inter-OFL.txt and source-serif-4-OFL.txt. Latin Extended covers Turkish. No runtime font service. Inter serves all UI; Source Serif 4 serves the answer word only.
